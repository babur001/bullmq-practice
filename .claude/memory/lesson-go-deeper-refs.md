When authoring Kafka course lessons, include a **"Go deeper"** section in relevant modules that points to specific **Stephane Maarek "Apache Kafka for Beginners v3"** (Udemy) sections/modules AND one or two canonical free articles/docs for detailed self-study on that lesson's topic.

**Why:** The user has the Udemy v3 sub and wants to reinforce each concept with the best external material, mapped precisely to the module — not just a generic reading list.

**How to apply:** Curate, don't dump. Name the exact Maarek section titles + the single best article (e.g. Confluent's "Incremental Cooperative Rebalancing" for rebalancing; KafkaJS docs for the API). Flag Java-only hands-on as "watch conceptually" (KafkaJS ≠ JVM), consistent with [[kafka-course]] RESOURCES.md which already maps resources→lessons. Keep it in the lesson's own voice/design. See [[course-teaching-style]].
